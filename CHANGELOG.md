# Changelog

All notable changes to this project are documented here.

## 1.0.0 — 2026-10-09

- First independent release of FHD Collection Organizer.
- Added configurable profiles with one or two category-set filters.
- Added filtered drag-and-drop ordering backed by item JSON and Collection index updates.
- Added permission checks, strict submitted-item validation, scoped admin CSS, installation documentation, and example configuration.
